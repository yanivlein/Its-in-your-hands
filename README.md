# לחיות טוב יותר – זה בידיים שלך · האתר

האתר החדש של ערכת הקלפים של רונית ליין – עמוד אחד, מעוצב, עם כל האנימציות, שמוביל להזמנה בוואטסאפ.
נבנה מתוך העיצוב ב־Claude Design ומוכן לעלות לאוויר ב־GitHub Pages.

## איך מעלים לאוויר

1. פותחים את **Claude Code** בתוך התיקייה הזו (`ronit-cards-site`).
2. מדביקים לו את ההודעה "פרסום ראשון" מהקובץ **PUBLISH_PROMPT.md**.
3. הוא ישאל על שם לריפו ויבקש אישור שהוא יהיה ציבורי (זה התנאי של GitHub Pages בחשבון חינמי – אין בתיקייה שום דבר פרטי).
4. בסוף הוא ייתן כתובת בסגנון `https://<שם-המשתמש>.github.io/ronit-cards/`.

כל ההוראות המפורטות בשבילו נמצאות ב־**CLAUDE.md** – הוא קורא אותן לבד.

## איך מעדכנים אחר כך

1. את השינוי עושים בצ'אט עם Claude (על קנבס העיצוב), כמו עד עכשיו.
2. מבקשים מ־Claude בצ'אט לעדכן גם את התיקייה הזו – הוא בונה אותה מחדש מהעיצוב ומוסיף שורה ב־CHANGELOG.md.
3. אומרים ל־Claude Code לדחוף (ההודעה "עדכון" ב־PUBLISH_PROMPT.md).

אם משנים משהו ישירות ב־Claude Code – ספרו על זה ל־Claude בצ'אט, כדי שהשינוי ייכנס גם לעיצוב ולא יימחק בעדכון הבא.

## מה יש בתיקייה

| מה | איפה |
|---|---|
| האתר עצמו (מה שעולה לאוויר) | `docs/` |
| קבצי העיצוב שממנו האתר נבנה | `design/` |
| הכלי שבונה את האתר מהעיצוב | `tools/` |
| כתובת האתר, כותרת, תיאור ופרטי קשר | `site.config.json` |
| יומן שינויים | `CHANGELOG.md` |
| הוראות ל־Claude Code | `CLAUDE.md` |
| הודעות מוכנות להדבקה | `PUBLISH_PROMPT.md` |

## לפני שמשתפים את הקישור

- **הצהרת נגישות ומדיניות פרטיות** (`docs/accessibility.html`, `docs/privacy.html`) הן טיוטות – רונית צריכה לקרוא ולאשר. רכזת הנגישות רשומה כרונית, עם הטלפון והמייל שלה.
- בסקשן "מי אני?", בתיבה "איך נולדו הקלפים", כתוב "בחורף 2026" – כדאי לוודא שזה נכון.
- אחרי הפרסום שווה לשלוח לעצמכם את הקישור בוואטסאפ ולראות שכרטיס התצוגה המקדימה (תמונה, כותרת ותיאור) נראה טוב.

## לצפייה במחשב לפני הפרסום

לחיצה כפולה על `docs/index.html` פותחת את האתר בדפדפן, עם כל העיצוב והאנימציות.
(רק כתובת האתר בתגיות השיתוף תהיה עדיין `SITE-URL` – זה מתעדכן בפרסום.)
